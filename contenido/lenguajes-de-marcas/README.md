# Lenguajes de marcas y sistemas de información

## Alcance

El mismo dato se publica en una web, se intercambia con otra empresa y se guarda en un fichero: cambia el formato, no el contenido. El módulo trabaja los tres lenguajes que cubren ese recorrido —HTML y CSS para presentar, XML con su validación para intercambiar— y su transformación.
