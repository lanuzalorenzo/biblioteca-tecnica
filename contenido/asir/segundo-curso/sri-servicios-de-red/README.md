# SRI. Servicios de red e internet

> **Módulo del ciclo ASIR.**

## Alcance

Un servidor deja de ser útil cuando nadie puede llegar a él: publicar una web, entregar correo o compartir ficheros exige configurar el servicio, el nombre, el certificado y los permisos. El módulo monta y asegura esos servicios.
