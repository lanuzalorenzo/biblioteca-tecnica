# SAD. Seguridad y alta disponibilidad

> **Módulo del ciclo ASIR.** Segundo curso, curso 2015/2016.

## Alcance

El módulo enseña a proteger un sistema por capas: el local donde viven los servidores, el almacenamiento que guarda los datos, el sistema operativo que los sirve y la red que los conecta. La segunda mitad —alta disponibilidad— busca que un fallo en cualquiera de esas capas no deje el servicio caído.
