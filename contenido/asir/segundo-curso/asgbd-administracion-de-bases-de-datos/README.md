# ASGBD. Administración de sistemas gestores de bases de datos

> **Módulo del ciclo ASIR.**

## Alcance

Instalar el motor es la parte fácil; lo que sostiene un sistema es quién puede leer qué, cómo se recupera tras un fallo y qué se mide cuando va lento. El módulo administra el gestor, no la consulta.

## Orden de estudio

| Unidad | Tema | Qué responde |
|---|---|---|
| UD1 | [Instalación y configuración segura](teoria/ud1-instalacion-y-configuracion-segura.md) | Dónde escucha, cuánta memoria y qué cuentas quedan |
| UD2 | [Usuarios, roles y privilegios](teoria/ud2-usuarios-roles-y-privilegios.md) | Quién puede leer qué y cómo se demuestra |
| UD3 | [Copias y recuperación](teoria/ud3-copias-y-recuperacion.md) | Cómo se vuelve a un estado anterior |
| UD4 | [Rendimiento y monitorización](teoria/ud4-rendimiento-y-monitorizacion.md) | Medir antes de tocar y vigilar lo que avisa |
| UD5 | [Disponibilidad y replicación](teoria/ud5-disponibilidad-y-replicacion.md) | Cómo sigue el servicio cuando el principal falla |
