# ASO. Administración de sistemas operativos

> **Módulo del ciclo ASIR.**

## Alcance

Administrar un sistema es saber qué se puede tocar sin romperlo: usuarios, permisos, servicios, directorios y copias. El módulo trabaja la administración diaria en Windows y Linux y la integración en un dominio.
