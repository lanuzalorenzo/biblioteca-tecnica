# GBD. Gestión de bases de datos

> **Módulo del ciclo ASIR.**

## Alcance

Un modelo de datos mal pensado se paga en cada consulta durante años. El módulo enseña a pasar de los datos al modelo relacional, a normalizarlo para que no se contradiga y a consultarlo con SQL, incluidos los objetos que ejecutan lógica dentro del motor.
