# ISO. Implantación de sistemas operativos

> **Módulo del ciclo ASIR.**

## Alcance

Instalar un sistema operativo no es meter un DVD y pulsar siguiente: hay que elegir el esquema de disco, decidir qué arranca primero, licenciar lo que se instala y dejarlo reproducible para veinte equipos iguales. El módulo cubre desde el arranque del equipo hasta el despliegue automatizado y el guion que hace el trabajo repetitivo.
